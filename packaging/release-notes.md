## Downloads

| File | Use it for |
| --- | --- |
| `ToolCheckout_*_x64-setup.exe` | **Windows 10/11 (recommended).** Installs for the current user only, no administrator rights, no UAC prompt |
| `ToolCheckout_*_x64-portable.zip` | Windows, nothing installed: unzip and run `ToolCheckout\ToolCheckout.exe`. Keeps all data in a `data` folder beside it |
| `ToolCheckout_*_amd64.AppImage` | Linux (x86_64, glibc 2.35+): `chmod +x`, then run it |
| `ToolCheckout_*_amd64.deb` | Debian 12+, Ubuntu 22.04+, Linux Mint 21+: `sudo apt install ./ToolCheckout_*_amd64.deb` |
| `SHA256SUMS.txt` | Checksums of the files above |

Other Linux distributions (Fedora, Arch, openSUSE, Void and more) can build
from source. The README has step-by-step commands for each.

### Windows: "Windows protected your PC"

These builds are not code-signed, so SmartScreen warns the first time you run
them. Click **More info**, then **Run anyway**. If Edge says the download
"isn't commonly downloaded", choose **… → Keep → Show more → Keep anyway**.

### Updating

Install or unzip the new version the same way. Your tools, people, history and
backups are kept. Make a backup first anyway (Settings → Data & backups →
Back up now).

See the [README](https://github.com/oreo1298/ToolCheckout#readme) for first-run
setup, barcode scanners, backups and PIN recovery.
